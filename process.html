내가 해결하고자 한 것 / 개선하고 싶은 것

VS Code · Codex에 전달한 요청

- '+ 할 일 추가'
- 수정
- 완료 처리
- 삭제

Plan:
- 선택한 날짜에 '+ 일정 추가'
- 일정 수정
- 일정 삭제

Today, Tasks, Plan에서 사용하는 입력 폼은 가능하면 같은 구조를 재사용해 줘.

숫자 뒤에 원형 또는 둥근 배경을 추가하는 방식으로 표현해 줘.

수업/활동을 여러 개 등록했을 때 한눈에 구별할 수 있어야 해.

수업/활동에 ‘기타’ 기본 항목 추가

내가 해결하고자 한 것 / 개선하고 싶은 것

병원, 약속, 쇼핑, 개인 용무처럼 별도 수업/활동을 만들기 애매한 데이터를 넣을 곳이 없었다.

VS Code · Codex에 전달한 요청
할 일 추가와 일정 추가의 '수업/활동' 선택 목록에 기본 항목으로 '기타'를 항상 포함해 줘.

'기타'는 사용자가 만든 수업/활동과 별개의 기본 항목으로 유지하고,
Settings에서 삭제할 수 없게 해 줘.

할 일 추가/수정, 일정 추가/수정에서 모두 선택 가능하게 해 줘.

수업/활동마다 색상을 설정했지만 Tasks 카드에서는 색이 거의 보이지 않아 색상 설정의 의미가 약했다.

VS Code · Codex에 전달한 요청

- 카드 왼쪽에 해당 수업/활동 색상의 얇은 세로 컬러 바
- 수업/활동 이름 앞에 작은 색상 dot
- 필요하면 아주 연한 tag/badge

카드 전체 배경은 현재 테마를 유지하고,
수업 색상으로 카드 전체를 강하게 칠하지 말아 줘.

VS Code · Codex에 전달한 요청

데스크톱:
- 기본 상태에서는 수정/계획/삭제를 숨김

모바일:
- hover가 없으므로 작은 '⋯' 더보기 버튼 표시
- 누르면 수정/계획/삭제 메뉴 표시

액션 때문에 카드 높이가 늘어나지 않게 해 줘.

앱 브랜드를 온원(ON-ONE)으로 변경

내가 해결하고자 한 것 / 개선하고 싶은 것

기존 CampusFlow보다 ‘모든 일을 한곳에 모으고, 할 일은 하나씩 해낸다’는 앱의 취지를 더 잘 표현하는 이름과 로고가 필요했다.

VS Code · Codex에 전달한 요청
현재 프로젝트의 브랜드를 CampusFlow에서 '온원 / ON-ONE'으로 변경해 줘.

브랜드 의미:
- 여러 일을 하나의 앱에서 관리한다.
- 할 일은 많아도 하나씩 하면 결국 해낼 수 있다.

브랜드 문구:
'모든 일은 한곳에, 할 일은 하나씩.'

기존 CampusFlow 표기를 모두 변경하고,
새로 추가한 투명 배경 로고를 헤더에 자연스럽게 적용해 줘.

VS Code · Codex에 전달한 요청

VS Code · Codex에 전달한 요청

- 기존 디자인과 기능은 변경하지 않기
- 수정 후 npm run build와 npm run dev로 정상 작동 확인

내가 해결하고자 한 것 / 개선하고 싶은 것

로그인과 실제 알림 기능을 사용하지 않는데 사람 아이콘과 벨 아이콘이 남아 있으면 사용자가 클릭 가능한 기능으로 오해할 수 있었다.

VS Code · Codex에 전달한 요청
헤더 오른쪽의 사용자 아이콘과 알림 아이콘을 제거해 주세요.

실제 계정/알림 기능을 사용하지 않기 때문에
